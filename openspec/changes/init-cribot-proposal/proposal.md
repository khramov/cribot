# Change: Initialize CriBot MVP — Plugin-based Financial Tracking Bot

## Why
Необходимо автоматизировать мониторинг финансовых идей и рыночных индикаторов. Вместо постоянного чтения Telegram-каналов и ручной проверки котировок, бот будет автоматически проверять заданные условия и присылать уведомления только когда нужно действовать.

**Ключевые боли:**
- Много источников информации (каналы, блоги, индикаторы)
- Нужно отслеживать разные условия для разных тикеров
- Хочется включать/выключать проверки независимо
- Стратегии меняются — нужна гибкость

## What Changes

### Phase 1: MVP (текущий scope)
- Инициализация Go-модуля с базовой структурой проекта
- Плагинная система с общим интерфейсом `Source`
- CSV-конфигурация для тикеров и порогов
- Уведомления через Telegram Bot API
- Деплой на Yandex Cloud Functions

### Phase 2: Расширения (future scope, не в этом proposal)
- AI-интеграция (NotebookLLM, OpenAI) для парсинга идей
- Telegram-бот для ввода идей голосом/текстом
- PWA с таблицей to_review
- Дополнительные плагины (Crimson strategy, Twitter и т.д.)

## Impact
- **Affected specs**: 
  - `bot-core` — ядро бота, конфигурация, уведомления
  - `source-plugins` — интерфейс плагинов и базовые реализации
  - `deployment` — Yandex Cloud Functions setup
- **Affected code**: Новый codebase в корне репозитория

## MVP Scope Constraints
- Single user (без аутентификации)
- CSV вместо БД
- Только Telegram для output
- 2-3 базовых плагина для демонстрации архитектуры
